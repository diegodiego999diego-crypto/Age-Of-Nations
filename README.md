# Age of Nations

A strategy game built with Godot 4.3.

## Project Structure
- `project/`: Main Godot project directory.
- `.github/workflows/build.yml`: GitHub Actions workflow for building Android APK.

## Build
The APK is automatically built on every push to `main` or `master` via GitHub Actions. You can download the artifact from the Actions tab.

## Package
- **Package Name:** `com.gith.ageofnations`
- **Repository:** [gith/Age-Of-Nations](https://github.com/gith/Age-Of-Nations)
